## Usage notes

- These images are **AI-generated visual concepts**, not screen-verified application screenshots.
- The brand board includes rasterised draft logo explorations; approve and rebuild any final logo as a standalone vector rather than cropping a production logo from the moodboard.
- Keep the high-resolution originals here. Generate compressed WebP/AVIF variants for performance before serving them in the Next.js marketing site.
- Use descriptive alt text for informative photography and empty alt text for decorative imagery.
- Treat logo, UI and typography details in the concept imagery as proposed styling, not established product behavior or third-party validation.
- Do not place personal employee information or production application data in website assets.
