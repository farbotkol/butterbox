# Butterbox Cloud Agent Proof of Concept

- Repository: `farbotkol/butterbox`
- Target branch: `copilot/finish-roadmap-for-app`

GitHub-native Issue-to-PR development lets a GitHub-hosted Copilot coding agent work from an issue, make changes on a branch, and open a pull request for review without the custom Mac-based controller.

This is a harmless test with no production impact. It does not access production systems or deploy anything.
